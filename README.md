# شمسة — مساعدة منصة «حِرَف مصر»

مساعدة ذكية (RAG) بتجاوب عن الحرف والتراث المصري من بيانات توثيق موثقة، **وكل معلومة معاها مصدرها**. جزء من مبادرة «مصر في ذاكرة المستقبل».

## بتعمل إيه
- بتفهم السؤال بالعامية المصرية وبتدوّر في بيانات الحرف.
- بترد بكود المصدر بعد كل معلومة، وبتشيل أي كود مش موجود في المقاطع المسترجعة.
- بتفرّق بين ٣ حالات: إجابة من بيانات المنصة، معلومة عامة (مكتوب بوضوح إنها مش موثقة)، أو سؤال برة الموضوع.
- بتفهم أسئلة المتابعة، وبتستخرج المحافظة والقسم من السؤال.
- أسلوب الرد: عادي، طفل، باحث، أو English.
- أفتار «شمسة» بيتحرك وبيتكلم بصوت (Edge TTS).
- بتخبي أسماء الحرفيين وأرقام تليفوناتهم.

## المعمارية
```
Excel الاستمارات ──► مقاطع (بطاقة حرفة + أقسام) ──► bge-m3 embeddings ──► Qdrant (in-memory)
                                                                              │
سؤال ──► بحث + تعزيز المحافظة ──► bge-reranker-v2-m3 ──► حد فاصل (threshold) ──► Gemini ──► إجابة + مصادر
```
- **Embeddings:** `BAAI/bge-m3` · **Reranker:** `BAAI/bge-reranker-v2-m3`
- **النموذج اللغوي:** Gemini (أو Claude لو `ANTHROPIC_API_KEY` موجود)
- **الواجهة:** Gradio

## هيكل الريبو
| المسار | الغرض |

| `notebooks/masr_rag.ipynb` | بناء الداتا والتجارب والتقييم (Colab) |

## تشغيل محلي
```bash
pip install -r requirements.txt
export GEMINI_API_KEY="..."     # أو ANTHROPIC_API_KEY
python app.py                   # http://localhost:7860
```
لازم فولدر `kb/` يكون فيه الملفات المطلوبة. أول تشغيل بينزّل الموديلين (حوالي ٥ جيجا).

## النشر على Hugging Face Spaces
1. اعمل Space جديد (Gradio).
2. ارفع `app.py` و`shamsa_head.js` و`requirements.txt` وفولدر `kb`.
3. انسخ `deploy/huggingface_space_README.md` كـ`README.md` في جذر الـSpace (فيه إعدادات `sdk_version` وبايثون).
4. ضيف `GEMINI_API_KEY` من Settings ← Variables and secrets.

على ZeroGPU البحث والـreranker بيتحجزلهم GPU بـ`@spaces.GPU`، وعلى CPU عادي الكود بيشتغل زي ما هو.

## الخصوصية والبيانات
- بيانات الاستمارات مصدرها وزارة الثقافة. النوتبوك فيه خطوة فحص خصوصية للمقاطع، وتعليمات شمسة بتمنع ذكر أسماء الحرفيين وأرقامهم.
- متحطش مفاتيح API في الكود أو في الـcommits. استخدم متغيرات البيئة أو Secrets.
